# Scaffold Builder

Creates a file system infrastructure based on the output of a Tree Utility.  All files are stubbed out with either a default TODO statement or the rest of the line from the structure following a '#'.  
These statements are inserted into the appropriate comment format for the type of file.

This utility takes an ASCII Project Directory layout graph (generated by AI) and creates the project directory infrastructure.

## Requirements

1. Accepts a parent directory where this file system structure is rooted.
1. Accepts a project language file (drives language-specific content of .gitignore)
1. If the parent directory is a in a Git Repo creates a New Branch named "Generator_<current date and time>. The program must abends if there are untracked and commited changes on the current branch with 
   a warning indicating that fact.
1. Accepts a file name with the directory structure, for file names creates a blank file with a language-appropriate comment "TODO: STUBBED FILE PLEASE IMPLEMENT"
1. Create or populate the .gitignore with the language-specific file types that should not be checked into the repository if the parent directory is in a Git Repo
